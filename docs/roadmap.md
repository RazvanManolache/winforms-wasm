# Roadmap

This project is a work in progress. The goal is to use AI to help adapt the platform around existing applications while preserving the business behavior people depend on. Smaller, testable changes reduce the scope of migration risk; they do not eliminate it.

- Expand compatibility through small, reproducible application workflows and generic runtime fixes.
- Make application configuration simpler without bundling applications into the browser build.
- Reduce time spent waiting for new dependencies and move more content loading to actual use.
- Improve layout, text, native-service boundaries, file handling, and canvas accessibility.
- Add reproducible native-versus-browser comparisons with capture provenance and explicit workflow coverage.
- Make the full test suite bounded and useful from a clean checkout.
- Document deployment and isolation before considering a shared hosting service.

There are no compatibility guarantees or release dates attached to this list. Small examples that expose a real behavior gap are especially useful contributions.
